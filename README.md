## 🌌 About the Project

**CELESTIUS** is an immersive web experience created to explore the intersection of frontend development, visual creativity, and interactive storytelling.

Rather than presenting a conventional static webpage, the project focuses on creating a memorable browsing experience through its visual identity, interactive interface, and dynamic presentation.

The project was developed using modern frontend tools and is deployed publicly through **GitHub Pages**.

## ✨ Highlights

- 🎨 **Immersive Interface** — A distinctive dark-themed visual design.
- 🖱️ **Interactive Experience** — Explore the interface through its implemented user interactions.
- 🎬 **Visual Storytelling** — A presentation designed to make browsing feel engaging and dynamic.
- ⚡ **Modern Frontend Workflow** — Developed and bundled using Vite.
- 📱 **Responsive Design** — Intended for exploration across modern browsers and screen sizes.
- 🌐 **Live Deployment** — Publicly accessible through GitHub Pages.

## 💻 Run Locally

Want to explore the code or run the project on your own machine? Follow these steps.

### Prerequisites

Install the following:

- [Node.js](https://nodejs.org/) — preferably an LTS version
- npm — included with Node.js
- [Git](https://git-scm.com/) — for cloning the repository

### 1. Clone the repository

```bash
git clone https://github.com/dheeranjai01-codes/celestius-immersive-experience.git
```

### 2. Enter the project directory

```bash
cd celestius-immersive-experience
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL printed in your terminal to explore the application.

## 🏗️ Build for Production

To create an optimized production build, run:

```bash
npm run build
```

Vite generates the production files in the `dist/` directory.

To preview the production build locally:

```bash
npm run preview
```

## 🌐 Deployment

CELESTIUS is deployed using **GitHub Pages** with GitHub Actions.

The deployment workflow:

1. Runs when changes are pushed to the `main` branch.
2. Installs project dependencies.
3. Builds the frontend application.
4. Publishes the generated `dist/` directory to GitHub Pages.

### Update the live website

After making changes locally, run:

```bash
git add .
git commit -m "Update immersive experience"
git push
```

GitHub Actions will automatically build and deploy the latest version.

## 🔒 Security and Repository Hygiene

- Never commit API keys, passwords, or private credentials.
- Keep local environment files out of version control.
- Exclude generated directories such as `node_modules/` and `dist/` from source control.
- Keep `package-lock.json` committed for reproducible dependency installation.
